# Fonts for TasteCraft Visual Engine

## Required Fonts

Download and place these font files in this directory:

### Noto Sans SC (recommended for MVP)
- Download from: https://fonts.google.com/noto/specimen/Noto+Sans+SC
- Place `NotoSansSC-Regular.ttf` and `NotoSansSC-Bold.ttf` here

### Source Han Sans CN (optional, higher quality)
- Download from: https://github.com/adobe-fonts/source-han-sans/releases
- Place `SourceHanSansCN-Medium.otf` here

## Fallback

If no custom fonts are found, the engine falls back to system fonts automatically.
